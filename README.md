# Funnel de KuzAcademy

Requiere Node.js 20.9 o superior y pnpm.

- `pnpm install --frozen-lockfile`: instalar las dependencias.
- `pnpm dev`: iniciar el servidor de desarrollo.
- `pnpm build`: generar la versión de producción.
- `pnpm start`: servir la versión de producción.
- `pnpm typecheck`: generar los tipos de Next.js y verificar TypeScript.
- `pnpm lint`: ejecutar Biome sobre el código de la aplicación.
